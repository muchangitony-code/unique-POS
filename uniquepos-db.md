## Critical: after schema changes
1. `pnpm run typecheck:libs` — regenerates `lib/db` declarations consumed by api-server.
2. `pnpm --filter @workspace/db run push` — applies DDL to the database.
3. Rebuild api-server: `pnpm --filter @workspace/api-server run build`.

**Why:** `lib/db/dist/schema/index.d.ts` is generated by `tsc --build`; if it's stale (shows `export {}`), all route files fail typecheck with "has no exported member" errors.
