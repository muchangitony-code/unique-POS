# Original UniqueERP infrastructure baseline

This directory contains source recovered directly from `Unique New.zip`, the approved structural source of truth for Unique POS. These files are being restored from the original architecture so the current monolithic deployment can be reconciled against the original API and frontend infrastructure instead of continuing to accumulate isolated replacement modules.

The restoration baseline includes the original quotation workflow and its supporting document infrastructure. Later reconstructed modules are not authoritative and may be replaced where the original architecture provides the intended implementation.
